# 모찌 (Mochi)

탐색기에서 파일을 끌다가 키 하나를 누르면 바퀴 메뉴가 떠서, 그 자리에서 다른 형식으로 바꿔 주는 Windows용 무료 프로그램입니다.

- 사진 · PDF · 한글 · 워드 · 파워포인트 · 엑셀 · 동영상 · 소리 · 자막 · 압축 파일
- 미리보기, 합치기, 용량 줄이기, 자르기, 가리기, 글자·QR 읽기 같은 도구도 바퀴 메뉴로 씁니다
- 원본은 그대로 두고 기본으로 같은 폴더에 새 파일을 만듭니다

사용법과 자세한 안내는 [matto.kr/work/mochi](https://matto.kr/work/mochi/)에 있습니다.

## 받기

[최신 판 받기](https://github.com/matto12-1/mochi/releases/latest)에서 둘 중 하나를 받으세요.

| | 설치판 `Mochi-Setup-1.0.0.exe` | 포터블판 `Mochi-1.0.0-portable.zip` |
|---|---|---|
| 켜는 법 | 설치한 뒤 시작 메뉴에서 | 압축을 풀고 `Mochi` 폴더의 `Mochi.exe` |
| Windows를 켤 때 같이 켜기 | 설치할 때 기본으로 켜짐 | 처음 켜면 기본으로 켜짐(설정에서 끄기) |
| 새 판이 나오면 | 새 설치 파일을 받아 두고 모찌를 끌 때 바꿈 | 알려 주기만 함. 새 zip을 받아 다시 풀기 |
| 지울 때 | Windows 설정의 앱 목록에서 제거 | 설정에서 자동 실행과 오른쪽 클릭 메뉴를 끄고 폴더 지우기 |
| 이럴 때 | 내 컴퓨터에서 계속 쓸 때 | 설치가 막힌 컴퓨터에서 쓸 때 |

두 판의 기능은 같습니다. 관리자 권한 없이 설치되고 실행됩니다.

## 처음 켤 때 파란 창이 뜨면

「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누르세요. 코드 서명 인증서를 사지 않은 무료 프로그램이라 뜨는 안내입니다.

## 파일과 인터넷

- 바꾸는 파일은 이 컴퓨터 안에서만 처리합니다. 모찌가 스스로 파일을 올리거나 보내지 않습니다. [공유]나 다른 프로그램으로 끌어 놓기는 직접 고를 때만 일어납니다.
- 인터넷은 새 판 확인(지금 판 번호만 GitHub에 묻습니다)과 설치판의 새 설치 파일 받기에만 씁니다. 자동 확인은 설정 「정보」에서 끌 수 있습니다.
- 설정과 기록은 `%LOCALAPPDATA%\Mochi` 폴더에 있고, 기록에는 파일 경로를 가려서 적습니다.

## 필요한 것

- Windows 10(2004 이상) · 11, 64비트
- 바꾸는 방향에 따라 한글이나 MS 오피스(워드·파워포인트·엑셀)가 깔려 있어야 합니다. PDF를 한글로 바꿀 때는 워드와 한글이 둘 다 필요합니다
- 아이폰 사진(HEIC)은 따로 깔 것 없이 읽습니다. HEIC 형식으로 저장하려면 Windows의 「HEVC 비디오 확장」이 있어야 합니다
- 사진 속 글자 읽기는 Windows의 한국어 문자 인식이 있어야 합니다
